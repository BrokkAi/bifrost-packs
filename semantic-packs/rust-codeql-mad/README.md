# CodeQL Rust stdlib summaries

This directory stages a separate MIT summary-only pack generated from CodeQL Rust Models-as-Data at codeql-cli/v2.27.4. It carries no declarations. Its activation matches the pinned `bifrost.rust-stdlib` pack in `semantic-packs/rust/`, and its provenance records that pack's source-set digest. The sibling policy-catalog JSON files are staged under `rules/bifrost.rust-codeql-security/catalogs/`; they are not semantic-pack shards. Neither asset is in a release recipe yet.
