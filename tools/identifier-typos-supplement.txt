# Brokk identifier typo supplement, one `wrong right` pair per line.
#
# Authored by Brokk and licensed under the Apache License, Version 2.0, like
# the rest of this repository. tools/aoo_autocorrect_typos.py merges it into
# rules/bifrost.javascript-codeql-quality/data/identifier-typos.txt after the
# Apache OpenOffice list.
#
# How the entries were produced: written by hand from programming vocabulary
# (identifiers, API and configuration words) as typing slips a programmer
# makes: transposed, dropped, doubled or swapped letters. Each wrong word was
# checked against a permissively licensed English word list (the public-domain
# Webster's Second International list in /usr/share/dict/words; SCOWL is also
# acceptable) and dropped if it is a word there or has three letters or fewer.
# Pairs that confuse two real words (strong/string, from/form, math/match,
# made/make, rule/role, newer/never, ceil/cell and the like) are never added.
#
# Authoring rule: entries are written by Brokk. Do not copy, consult, diff
# against or select entries using codespell, client9 or golangci misspell,
# crate-ci typos-dict, Wikipedia's lists of common misspellings, LibreOffice
# AutoCorrect, CodeQL's TypoDatabase, or any table derived from them. Typos
# found in typo-fix commits of BrokkAi's own repositories may be added.
